# 财小全 Agent 全量代码审查与修复清单

审查对象：`财小全-比赛修正版_修复版.html`  
审查方式：静态代码检查、关键函数追踪、JavaScript 语法检查、针对月份归并逻辑的定向测试。  
定位：比赛演示原型；不按生产银行系统标准重写。  

## 1. 本轮新增发现与修改

### P1：一键演示流水与看板月份窗口不一致（已修复）
- 问题：看板基线固定为 2026 年 7—9 月，但一键演示原先按电脑当前年月生成日期。电脑时间进入 2026 年 10 月后，演示流水会落在看板统计窗口之外，导致“一键演示”导入 12 笔却不进入三个月图表。
- 修改：演示流水固定写入 `2026-09`，与现有演示看板窗口一致。
- 影响：一键演示的月报、流水列表与看板窗口更容易对齐；演示日期是固定场景数据，不代表实时交易。

### P1：只有月日、没有年份的流水可能被错误计入 2026 年（已修复）
- 问题：`txnMonth()` 可以解析 `9/12`，但 `txnYear()` 返回空值；原 `merge()` 仍会按月份将它计入 2026 年 9 月，违反“不推断年份”的口径说明。
- 修改：只有月份、没有年份的记录现在单独计数并排除在 2026 年 7—9 月看板合计之外；同时增加非法月份防御计数。
- 影响：不再把无法确定年份的记录擅自算入当前看板。

## 3. 仍存在的限制 / 未完全解决项

### R1：尚未完成完整浏览器交互回归（P1）
- 当前确认 HTML 内联 JavaScript 可通过 `node --check`。
- 当前环境尝试使用 Chromium 无头打开页面时超时，不能据此声称页面完整运行通过。
- 需要人工或可控浏览器测试：切换身份、导入/删除流水、刷新、退出演示、保存/删除贷款方案、恢复备份。

### R2：审计哈希不是密码学安全签名（P1，属于架构限制）
- 当前 `cxqHash()` 是简单 32 位非密码学哈希，浏览器本地日志可被用户清除或修改。
- 适合比赛演示中的链式留痕，不适合宣传为银行级、不可篡改或法律级审计。
- 生产级实现需要服务端签名、权限控制、可信时间源与独立日志存储；本次按演示定位未重构。

### R3：JSON 备份是全局替换，不是按当前账号合并（P1，操作风险已在确认框提示）
- 导入确认框明确说明会替换本机流水、定时任务和分摊单。
- 导入前建议先导出备份；不应把导入按钮描述成“只恢复当前账号”。
- 由于这是全局备份恢复，恢复后可能覆盖当前浏览器内其他账号的本地流水；若希望改成账号级导入，需要另行调整备份格式和交互。

### R4：CSV 解析器不支持带换行符的引号字段（P2）
- 当前解析器逐行处理并支持引号转义、逗号和制表符，但不支持单个字段内部包含换行符的复杂 CSV。
- 常见银行流水导出通常可用；遇到备注字段内含换行的文件可能被拆坏。导入失败时应检查原始 CSV，或后续引入成熟 CSV 解析库。

### R5：CSV 日期要求完整年月日（P2）
- `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY.M.D` 可按当前规则识别并校验。
- `9/12`、`9月12日` 等缺少年份的 CSV 日期会被跳过，避免擅自推断年份。

### R6：本地存储不是跨设备同步或加密保险库（P1，架构限制）
- 流水、方案、审计和部分设置保存在浏览器 `localStorage`。
- 清理浏览器数据、换浏览器/设备或隐私模式限制可能导致数据丢失；不应存放真实银行卡密码、身份证原文、API 密钥等敏感信息。

### R7：部分模块仍是预置演示值（P1，需保持披露）
- 健康分趋势、税务、贷款、保障、部分企业/家庭基线仍为预设演示参数；导入流水不会自动重算这些模块。
- 页面已有多处说明，但演示讲解中仍应主动说清楚“流水看板与税贷模块当前独立”。

### R8：一键演示备份状态只在当前页面内存中（P2）
- `cxqDemoBackup` 是内存变量，刷新页面后不会保留“退出演示时恢复”的备份快照。
- 若载入演示后直接刷新，演示流水会作为普通本地流水保留，无法自动回滚到载入前状态。建议演示后在同一页面再次点击退出，或先导出备份。

### R9：反诈规则是简单启发式，不是模型风控（P1）
- 当前规则主要识别大额整数支出、同商户同日重复支出；存在误报和漏报，不能推断交易安全或确认诈骗。
- 已在提示文案中说明规则范围和能力边界。

### R10：税务结论依赖演示前提（P1）
- 页面中的税额计算是条件化演示，不应视为正式申报金额。
- 纳税人身份、业务性质、销售额口径、计税期间、发票与优惠适用条件均需核实；本次代码审查不构成税法适用意见。

## 4. 关键功能数据口径

- **财务看板**：企业/个人/家庭演示基线 + 当前账号流水中可明确归入 2026 年 7—9 月窗口的记录。
- **我的流水 / CSV 导出**：仅当前账号的手动录入、CSV 导入及一键演示流水。
- **月报导出**：仅当前账号本机流水，不包含看板预设基线。
- **税务 / 贷款 / 健康分 / 保障**：当前仍使用独立的预设演示参数，不会因流水导入或删除而自动重算。
- **审计轨迹**：浏览器本地日志，提供演示回放和基本链完整性检查，不是不可篡改服务端审计。

## 3. 本轮继续修复（账号删除保护与本地数据结构容错）

### P1：删除流水的确认弹窗可能引用过期索引（已修复）
- 问题：删除操作先保存数组下标，二次确认弹窗打开期间，若数据状态发生变化，旧索引可能已指向另一条流水；原回调没有重新核对目标记录。
- 修改：打开删除确认前验证流水存在且属于当前账号；确认后再次校验索引、账号归属、日期、商户、金额和类型，若记录已变化则取消删除并要求刷新列表。
- 影响：降低误删其他记录或跨账号流水的风险。
- 验证：静态代码检查；真实浏览器的并发/快速切换操作仍需回归。

### P2：浏览器本地存储中的 JSON 结构损坏时可能导致首屏逻辑异常（已修复）
- 问题：`cxf-txns`、`cxf-sched`、`cxf-split` 即使能成功 JSON 解析，也可能是对象或其他非数组类型，后续代码调用 `.filter()`、`.map()` 时可能报错。
- 修改：恢复时显式检查 `Array.isArray()`；结构不是数组则回退为空数组，避免把错误结构交给后续渲染。
- 影响：增强本地存储结构异常时的容错性。回退为空数组不会自动修复或覆盖原存储值，用户仍应优先导出可用备份。
- 验证：静态代码检查；本地存储被手工篡改的浏览器故障注入尚未实测。

## 6. 本轮新增审查：空会话账号切换时的旧会话 ID（已修复）

- 问题：`setAccount()` 在目标账号没有可用会话时，原逻辑使用 `firstSessOf(...) || state.sess`，会保留切换前账号的会话 ID。即使后续会话读取函数通常会返回空对象，这个旧 ID 仍可能影响新消息历史键、对话上下文或界面状态。
- 修改：改为 `state.sess = firstSessOf(mode,acctId) || null`。目标账号没有会话时清空旧 ID，不再继承上一个账号的会话标识；用户可以通过“新建对话”创建本账号会话。
- 验证：修改后重新提取 HTML 内联 JavaScript，`node --check` 通过。
- 未完成验证：尚未在真实浏览器中构造“目标账号会话列表为空”的场景执行交互回归。

## 本轮补充审查：CSV 导出公式注入风险

### 发现

流水导出时，商户/备注字段虽然进行了 CSV 双引号转义，但如果文本以 `=`, `+`, `-`, `@` 等字符开头，部分电子表格软件仍可能将其解释为公式。由于商户/备注可能来自外部 CSV 导入，因此这属于需要处理的导出安全边界。

### 修改

- 新增 `cxqCsvCell()`，统一对 CSV 文本字段进行双引号转义。
- 对可能被电子表格解释为公式的文本字段添加前置单引号。
- 日期、类型、商户/备注统一通过文本字段转义函数输出；金额列仍由程序生成数值字符串，保留可计算性。

### 验证

- 完整内联 JavaScript 提取后执行 `node --check`：通过。
- 说明：尚未在 Excel 与 WPS 中分别实测不同版本对前置单引号的呈现行为；该修复降低公式注入风险，但不能替代对所有电子表格软件的兼容性测试。

## 8. 最终收尾修复：贷款方案数量与持久化上限一致（已修复）

- 问题：持久化函数只保存最近 100 个贷款模拟方案，但页面内存数组此前可能继续累积超过 100 个。达到上限后，页面当前会话中可见的方案与刷新后恢复的方案可能不一致。

## 10. 比赛演示前的最终已知限制

1. **演示基线与导入流水不是同一数据源。** 部分模块仍使用预设基线；导入流水只影响明确接入该流水的视图，不能宣称所有财务模块都会自动联动重算。
2. **身份切换是前端演示隔离，不是服务器授权。** HTML 内的预置账号和本地存储不能替代后端鉴权与数据权限控制。
3. **审计链为本地完整性提示机制。** 本地数据可被清除或篡改，不应描述为不可抵赖的合规审计。
4. **JSON 恢复属于覆盖操作。** 需要先备份；当前不是按账号选择性合并恢复。
5. **外部模型调用的隐私边界取决于配置的服务商。** 即使代码做了常见号码脱敏，也不应把脱敏描述为完全匿名化。
6. **本轮未完成真实浏览器交互测试。** 在交付或比赛前，仍需在目标浏览器和手机端打开文件，执行账号切换、导入/导出、备份恢复、贷款方案保存/删除、审计刷新恢复和打印下载测试。
