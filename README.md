# 财小全 · AI 财务中枢（比赛提交版）

> 一个 Agent · 三种模式 · 四轮驱动 · 一重护栏
> 面向企业经营者、个人与家庭的财务 AI 助手 —— 账、税、贷、保在同一本账簿上完成。

- 作品编号：CXQ-2026
- 源码版本：`财小全agent.html`（V1.1，单文件 376.8 KB）
- 技术形态：单 HTML + 原生 JavaScript（ES5），零后端、零构建、零外部依赖
- 数据形态：全部为虚构演示数据，保存在本机浏览器，不上传

---

## 一、30 秒跑起来

方式 A（最快，零环境）：直接打开在线演示地址 <https://4m78se5ar2y1f.doubao.link/app/app_17fhd5sv7t3> —— 手机 / 电脑浏览器均可，无需下载、无需安装任何依赖。

方式 B：双击本地 `src/财小全agent.html`，Chrome / Edge 直接打开即可。

方式 C（推荐本地调试，避免 `file://` 的跨域限制）：

```bash
# 任选其一，在 src 目录下执行
python -m http.server 8080
npx serve .
```

然后访问 `http://localhost:8080/财小全agent.html`。

进入后默认是**企业模式 · 王建国（经营者 · 主账号）**；右上角头像可切换三种模式与七个账号。

## 二、三种模式与七个账号

| 模式 | 账号 | 角色 | 权限 | 可见粒度 | 出口 |
|---|---|---|---|---|---|
| 企业 | operator | 经营者 · 主账号 | read / write / main | 明细 | 财务总览 / 对话 |
| 企业 | investor | 投资人 · 子账号 | read | 摘要 | 对话 / 总览 |
| 个人 | self | 本人 · 主账号 | read / write / main | 明细 | 对话 / 我的账户 |
| 个人 | advisor | 财税顾问 · 子账号 | read | 结论 | 对话 |
| 家庭 | keeper | 管钱者 · 主账号 | read / write / main | 明细 | 总览 / 对话 |
| 家庭 | member | 消费成员 · 子账号 | read | 摘要 | 对话 |
| 家庭 | elder | 长辈 · 关怀模式 | read | 结论 | 大字版（只读、无资金入口） |

用子账号问工资、薪酬、逐笔流水、卡号，会得到越权提示而不是答案——这是演示的重点之一。

## 三、赛题场景覆盖

| 场景 | 覆盖 | 怎么演示 |
|---|---|---|
| 智能转账 | 完整 | 说「给张三转 3000，货款」→ 生成待确认指令，不执行 |
| 账单分析 | 完整 | 导入 CSV 或点「一键演示」→ 看板按 2026 年 7–9 月归月 |
| 理财操作 | 部分 | 说「这月闲钱怎么安排」→ 只给周转/应急/定期比例，不推荐产品 |

| 订阅代扣 | 完整 | 说「扫一下我的订阅」→ 到期提醒，取消需二次确认 |

理财操作只做到「留多少、放哪里」，不出产品名、收益率与购买入口。

## 四、五分钟演示路线

1. **总览**：结余、健康分、四轮状态、今日建议（对应视频 0:38–1:05）
2. **催款**：说「今天该收谁的钱」→ 应收合计 24,200、逾期 21,000、最长 49 天
3. **缺票**：说「这张票能抵多少税」→ 缺票清单与补票优先级
4. **报税**：说「三季度要交多少税」→ 342,500 × 1% = 3,425
5. **信贷**：我的账户 → 打开反事实模拟器 → 拖提前还款额，看 DTI 8.4% → 更低
6. **闲钱**：说「这月闲钱怎么安排」→ 先补 3 个月应急金，再按 40/30/30 分配
7. **家庭**：切到李梅 → 家庭账单 → 再切张奶奶（大字只读版）
8. **技能库**：18 项技能 / 6 大域，子账号点击锁定项会提示申请
9. **审计**：审计面板 → 链状态、逐条回放、导出报告
10. **防诈**：说「客服让我把钱转到安全账户」→ 拦截 + 96110

## 五、接入模型（可选）

1. 顶部「模型设置」填入 API Key、Base URL（默认 `https://api.deepseek.com/v1`）与模型名（默认 `deepseek-chat`）；
2. Key 只写入 `sessionStorage`，关闭标签页即失效，不进入导出备份；
3. 未填 Key 时，长句提问走本地离线应答，核心测算与卡片功能不受影响；
4. 上下文只装配当前账号数据，发送前对卡号/手机号/身份证做掩码。

## 六、数据与隐私

- 全部数据落在本机 `localStorage` 的 12 个键内，不上传、不同步；
- 清除浏览器数据即彻底清除；建议先「导出备份」再清；
- 备份 JSON 不含密钥，但恢复会覆盖本机流水、定时任务与分摊单，确认框已提示；
- 审计日志是本地链式哈希（FNV-1a 32 位），用于演示回放与断链定位，不具备法律级不可篡改能力。

## 九、已知限制（不隐藏）

1. 税、贷、保的销售额、DTI 分母与保障缺口已改为按账本实时重算（`cxqLinked()`），但个税、贷款明细（月供/余额）、已有保额与责任基数仍取预设值，不随导入流水变化；
2. 身份切换是前端演示隔离，不是服务器授权；
3. 审计链可被本机清除，非密码学签名；
4. JSON 恢复是全局覆盖，不支持按账号合并；
5. 一键演示的回滚快照仅在页面内存，刷新后失效；
6. CSV 解析不支持字段内含换行；缺年份的日期会被跳过而不推断；
7. 尚未完成真实浏览器与移动端端到端回归，验收清单中已标注「未完成」。

完整评估见 `docs/财小全-AI财务中枢-安全自评报告.pdf`，技术细节见 `docs/财小全-AI财务中枢-技术文档.pdf`。
